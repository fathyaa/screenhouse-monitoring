Laporan Pengujian Beban — REST API & WebSocket

Beban dinaikkan bertahap dari kecil ke besar. Tiap titik = satu run k6 steady-state di level itu. Yang dibaca: throughput (berapa banyak ditangani per detik) dan latency (berapa lama tiap request ditangani, persentil p50/p95/p99). Titik di mana throughput berhenti naik tapi latency melonjak = kapasitas maksimum sistem.
